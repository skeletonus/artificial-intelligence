# Данные проекта

В этой папке хранятся данные, используемые для обучения/валидации/тестирования моделей, данные для работы сервиса

Используемые данные: 
- ml-latest-small. Датасет на 100 000 записей. Использовался в экспериментах 1-5, а также при обучении сервисной CatBoost модели
- ml-32m. Датасет той же структуры, но уже на 32 млн. записей. Использовался в эксперименте 06, а также для составления каталога фильмов и обучения сервисной SVD модели

Организация:
- `production\` - данные, используемые для сервиса. Содержит каталог фильмов 
- `ml-latest-small` - Содержит сырую выгрузку из архива, сырые train/val/test выборки и обогащенные train/val/test выборки
- `ml-32m` - Содержит сырую выгрузку из архива, сырые train/val/test выборки
