# Ноутбуки проекта

В эту папку помещаются **экспериментальные ноутбуки**:

Организация:
- exp01_data_and_EDA - установка, анализ, обогащение и разбиение датасета ml-latest-small (MovieLens)
- exp02_LinearRegression - обучение и оценка моделей на основе линейной регресси 
- exp03_DecisionTree - обучение и оценка моделей на основе деревьев и ансамблей
- exp04_NeuralNetworks - обучение и оценка моделей на основе нейронных сетей
- exp05_CollaborativeModels - обучение и оценка коллаборативных моделей моделей
- exp06_FinalDataAndModels - установка, анализ, обогащение и разбиение датасета ml-32m (MovieLens). Обучение обучение и оценка моделей для cold- и worm-start. Определение функционала итогового проекта на основе полученных моделей
