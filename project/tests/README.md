# Тесты проекта

В этой папке находятся тесты проекта

Организация: 
- `test_setup.py` - Проверяет успешную установку всех компонентов сервиса: пользовтельские данные, справочники, модели, метаданные
- `test_api.py` - проверяет работу API: отправляет запросы ко всем реализованным эндпоинтам и проверяет статусные коды и структуру ответов. 
- `conftest.py` - добавляет корень проекта в пути импорта и содержитS общие настройки для запуска тестов.

Запуск: 

```bash
cd project
python -m pytest -q
```
