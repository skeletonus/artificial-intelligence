# src/models

Отвечает за реализацию, обучение и сохранение моделей рекомендательной системы.

Организация:

- `base.py` - базовые интерфейсы и общая логика работы с моделями.
- `catboost_model.py` - обучение и использование модели CatBoost.
- `svd_wrapper.py` - обучение SVD-модели и извлечение её глобальных артефактов.
