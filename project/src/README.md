# Исходный код проекта

В этой папке размещается **основной код проекта**, который используется для:

- подготовки данных;
- обучения моделей;
- инференса (получения предсказаний);
- запуска сервисов (API/CLI/скриптов).

Организация:
- `api\` - API и схемы запросов
- `data\` - загрузка и обработка данных.
- `features\` - создание признаков и каталога фильмов.
- `models\`- модели CatBoost и SVD.
- `recommenders\` - логика рекомендаций.
- `users\` - пользовательские анкеты и оценки.
- `utils\` - конфигурация, пути и работа с файлами.
- `setup_project.py` - подготовка данных и обучение моделей.
