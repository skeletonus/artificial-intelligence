# src/recommenders

Отвечает за формирование cold-start и warm-start рекомендаций.

Организация:

- `cold_start.py` - формирование рекомендаций на основе жанровой анкеты пользователя.
- `warm_start.py` - формирование персональных рекомендаций на основе пользовательских оценок и SVD.
- `common.py` - общие функции загрузки, фильтрации и форматирования рекомендаций.
- `service.py` - объединение логики рекомендательной системы для использования в API.
